AI Design Process

Pipeline · Contratos JSON

Contratos, con manzanas

Piensa en un contrato JSON como la ficha de una receta en la cocina: no es el plato (Figma), sino la etiqueta que dice exactamente qué ingrediente es cada componente, sus estados y tokens — para que dev no adivine.

Figma organizado→ Higiene→ Verify vs Android + JSON→ Contratos en draft→ Sello humano portero / Lead (~10–15 min)→ Eng consume solo lo sellado

En el PoC probamos…

  • Prueba 3: ¿sale un draft usable para el portero? — Sí, draft; no es el handoff eng.
  • Verify: gaps honestos Figma↔spec↔código, sin inventar.
  • Sello: el portero / Lead Designer valida en ~10–15 min — no se automatiza.
Analogía

Receta + etiqueta

Figma = plato presentado. Contrato JSON = etiqueta con nombre del componente, props/estados y tokens. El sello = chef jefe que aprueba la etiqueta antes de que cocina (eng) la use.

Handoff sellado

Cómo luce el entregable

Eng recibe un pack sellado: contrato JSON alineado al componente en Figma. Ejemplo ilustrativo — no es el archivo real del PoC.

SELLADO Componente Figma

Button / Primary

Variantes: default · hover · disabled

theme: primary size: md state: enabled
Continuar

Tokens: color.action.primary, spacing.md, radius.pill

Ejemplo · contrato JSON (fragmento)
{
  "component": "Button",
  "variant": "primary",
  "props": {
    "label": "Continuar",
    "disabled": false
  },
  "states": ["default", "hover", "disabled"],
  "tokens": {
    "bg": "color.action.primary",
    "radius": "radius.pill"
  },
  "sealedBy": "portero/lead-designer",
  // pack sealed · handoff eng
}

Solo lo sellado sale del pipeline — coherente con prueba 4: pack sealed · handoff.

Roadmap y qué pedimos hoy

2. Qué pedimos hoy

Apoyo para socializar el método al resto del equipo. Reconocimiento de tiempos de adopción razonables.

Adopción

  • Shadow 2–3 semanas
  • Playbook +2–3 semanas
  • Workshops internos 2-3 semanas
  • Rollout ligero desde mes 2

En paralelo: Formación intensiva en Claude Code, GitHub, Design System y Contratos JSON.
Imprescindible: Diseño debe tener acceso a repositorio y SDD.

Entregables

  • Shadowing reports
  • Playbook consumible por todo el equipo
  • Workshops evidence
  • Acceso a cursos (p. ej. Claude Code)
SEÑAL CLAVE

Asentar esta práctica en Diseño tomará 3–6 meses: proceso nuevo (cliente + interno) y curva técnica + accesos que hoy el equipo no tiene.
